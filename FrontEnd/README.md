# Le Fil d'Or — FrontEnd

React + SCSS modules (Vite), right-to-left Arabic.

```bash
npm install
npm run dev      # development
npm run build    # production build in dist/
npm run lint
```

Settings live in `.env` (see `.env.example`): `VITE_API_URL` = address of the BackEnd.
Rebuild after changing it. Full documentation is in the root `README.md`.
